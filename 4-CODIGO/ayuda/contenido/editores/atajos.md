| Atajo | Qué hace |
|---|---|
| Ctrl K (o Alt / dentro del texto) | Paleta de comandos: buscar documentos, espacios y acciones |
| Ctrl Z / Ctrl Y | Deshacer / rehacer (solo tus cambios) |
| Ctrl S | Guardar versión |
| Ctrl . | Modo enfoque |
| Ctrl B / Ctrl I / Ctrl U | Negrita / cursiva / subrayado |
| Ctrl F | Buscar y reemplazar |
| Ctrl D / Ctrl R | En la hoja: rellenar hacia abajo / a la derecha |
| ? | Ver todos los atajos |
| Esc | Cerrar ventanas y salir del modo enfoque |
