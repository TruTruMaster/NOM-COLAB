| Dónde | Qué se necesita |
|---|---|
| Computadora | Chrome, Edge, Firefox o Safari recientes. Para instalarlo como programa: Chrome o Edge |
| Celular | El navegador del celular (Chrome, Firefox, Samsung Internet, Safari) o la app de Android |
| App de Android | Android 7 o más reciente; Android 8 o más para que el teléfono comparta |
| Pantalla | Desde 360 píxeles de ancho (cualquier celular actual) |
| La computadora que comparte en el salón | Windows o Linux; el paquete ya trae Java |

**No hay app para iPhone** ni para computadora: en iPhone y en la computadora se usa el navegador (y
en la computadora se puede [instalar como programa](ayuda:empezar/instalar-computadora)).
